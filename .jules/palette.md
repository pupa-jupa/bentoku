## 2024-10-08 - Keyboard Accessibility in Phaser Canvas Games
**Learning:** Adding standard DOM keyboard accessibility attributes (like `accesskey` or modifying canvas dimensions for hints) is ineffective and breaks layout in fixed-width Phaser canvas games because the UI lacks HTML ARIA elements. Furthermore, simple event listeners can cause rapid accidental execution from held-down keys or trigger unintentionally when typing in other contexts.
**Action:** Implement keyboard shortcuts using silent global event listeners (e.g., `this.input.keyboard?.on('keydown-U')`) within Phaser scenes. Always explicitly check that no modals are active (`!this.modal`), HTML inputs are not focused (`document.activeElement?.tagName !== 'INPUT'`), and `event.repeat` is falsy to prevent unintended rapid execution. Crucially, unbind these listeners in the scene's `SHUTDOWN` event to prevent memory leaks.
